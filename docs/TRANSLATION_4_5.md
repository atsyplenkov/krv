# English terminology review — 4.5

The Russian About copy follows the author's 4.5 specification, with only the agreed continuation and typo corrections. The English copy preserves the meaning while using natural English sentences. User-entered names, comments and field data are never translated.

Reference consulted: WMO/UNESCO International Glossary of Hydrology, WMO-No. 385, multilingual edition:
https://old.wmo.int/extranet/pages/prog/hwrp/publications/international_glossary/385_IGH_2012.pdf

Terms checked include sounding (hydrometry), current meter, discharge, cross-section, hydraulic radius and wetted perimeter. Existing terms that are suitable were retained. Measurement-depth headings replace the literal “horizon”; subsection area/discharge replace ambiguous section/partial discharge labels. Ice conditions and aquatic vegetation describe the special-condition selection without changing its calculation rules. Effective water depth excludes ice thickness, as in the established input model.

The review covers the common translation dictionaries and all new About pages/warnings. A scan of literal Russian tr(...) calls found no unmapped literal strings. Dynamic warning details translate bank labels and units. CSV headers remain fixed for batch processing; new JSON field names remain stable.

Licence UI: full bundled licence/notice texts remain available offline through LicenseRegistry and the local Apache asset. Only identical rendered notice bodies are grouped, retaining every associated component name and copyright notice. Reference: https://www.apache.org/licenses/LICENSE-2.0.html and https://api.flutter.dev/flutter/foundation/LicenseRegistry-class.html .
