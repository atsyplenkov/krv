# Сообщения об уязвимостях / Security reports

Не публикуйте секреты или персональные данные в Issues.
Сообщайте об уязвимостях автору: olegegkas@gmail.com.
Укажите версию, шаги воспроизведения и возможные последствия на обезличенном примере.

Report vulnerabilities privately to olegegkas@gmail.com, including the version,
reproduction steps and impact using anonymized data. Do not post credentials in issues.

Исправления планируются для актуальной версии. Сроки ответа и исправления не гарантированы.
Security fixes target the current version; no response-time or maintenance SLA is promised.
