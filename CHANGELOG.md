# История версий

## 4.6.0+14 — 2026-10-20

- Независимые шеститочечные коэффициенты для обычных условий и ледовых явлений / растительности; прежние настройки загружаются без изменения результатов.
- Формулы средней скорости на вертикали под таблицами коэффициентов, уточнённые справки и область действия настроек.
- Необязательное поле «Проект», точный и частичный поиск по проекту, сортировка по расходу воды.
- Необязательная толщина льда и явное «н/д» / `N/A`. График строится при наличии значений на обоих берегах по доступным точкам, с вертикальными границами у берегов.
- Отметка ледостава в списке измерений, компактные таблицы и короткие подсказки ввода.
- Последовательное размещение таблиц PDF; альбомная страница требуется только для широкой таблицы. Единая схема CSV из 89 столбцов: `project` добавлен в конец, отсутствующее значение остаётся пустым.
- Все изменения на русском и английском языках. Сохранены исправления прокрутки и лицензий из 4.5.1.

English: independent six-point weighting tables with backward-compatible migration;
explicit mean-velocity formulas and scope help; optional project with search/export;
numeric discharge sorting; optional ice thickness and continuous available-point
ice profiles with bank outlines; compact tables; adaptive PDF page flow; CSV
schema 4.6 with an appended project column; bilingual terminology and input hints.


## 4.5.1

- Сохранена позиция списка при возврате из измерения.
- Восстановлен стандартный экран лицензий Flutter вместо раскрывающихся текстов с повторяющимися названиями.

## 4.5.0

- Тексты и навигация «О приложении», текущая дата цитирования, компактный просмотр лицензий офлайн.
- Импорт в настройках, поиск без текстовой кнопки, тёмные карточки и отдельные предупреждения.
- Название эффективного метода и средняя скорость над полями скоростей.
- Ограничение линий уровня воды фактическими урезами.
- Обратимое исключение осушенных скоростных вертикалей; резервный вертикальный берег; расчёт разделённого сечения с предупреждениями.
- Двуязычные предупреждения в интерфейсе, PDF и CSV, дополнительные машиночитаемые сведения в существующей схеме CSV.
- Английский перевод уточнён по гидрологической терминологии.

## 4.4.0 (подготовка выпуска)

- Светлая, тёмная и системная темы; отдельный раздел «О приложении».
- Прямой ввод типа дна и толщины льда, отдельный график льда.
- Поправка уровня без изменения исходных промеров, вычисление новых урезов и выбор способа экстраполяции берегов.
- Защита расчёта при осушении скоростных вертикалей и разделении водного сечения.
- Подтверждение очистки скоростей при изменении глубин.
- Единая схема CSV для старых и новых измерений, новые сведения в PDF и .krv.
- Лицензия Apache-2.0, сведения для цитирования и правовые документы RU/EN.

## 4.3.0

Улучшены ввод промеров и второго берега, подсказки глубин, таблицы результатов и переключение языка.

## 4.2.0

Экспорт и импорт измерений с фотографиями через архивы .krv.
