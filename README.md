# Калькулятор расходов воды / Water Discharge Calculator

Версия **4.5.1+13**, Android applicationId: `krv.app`.
Автор: **Олег Лошков / Oleg Loshkov**. Лицензия: Apache License 2.0, полный текст в LICENSE.

Приложение навайбкожено с помощью ИИ-ассистента.
This app was vibe-coded with the help of an AI assistant.

КРВ помогает записывать полевые промеры и скорости течения, рассчитывать расход воды и характеристики поперечного сечения, хранить измерения и формировать отчёты без интернета. Доступны русский и английский интерфейсы, фотографии с подписями, PDF, CSV и перенос измерений в файлах .krv.

## Изменения 4.5

- Уточнены тексты «О приложении» и английский перевод; цитаты ГОСТ/ISO 690 используют текущую дату. Лицензии доступны без интернета в раскрывающемся списке.
- Импорт .krv перенесён в настройки; экспорт выбранных измерений остаётся на главном экране.
- Поиск представлен значком; исправлены контраст карточек и графиков, отдельные блоки предупреждений и отметка предупреждений у завершённых измерений.
- Линии уровня воды ограничены обводнёнными участками профиля.
- Осушенные скоростные вертикали временно исключаются из Q без удаления наблюдений. Если в воде не осталось скоростных вертикалей, расход не определён, а не равен нулю.
- При невозможности продолжить склон применяется вертикальный берег только для этой стороны, с предупреждением. Выбранный способ сохраняется.
- Разделённое сечение допускает расчёт с явным предупреждением: существующий алгоритм не моделирует отдельные рукава и их береговые коэффициенты.
- CSV сохраняет единую схему из 88 столбцов; сведения об исключённых вертикалях и резервном способе достраивания добавлены в JSON-метаданные.

## Изменения 4.4 (предыдущая версия)

- Системная, светлая и тёмная темы с предварительным просмотром. PDF остаётся светлым.
- Экран «О приложении»: сведения об авторе и проекте, методические источники, ссылки на код и сообщения об ошибках, цитирование, лицензия, конфиденциальность и условия использования.
- Тип дна вводится сразу при добавлении промера и второго берега. При ледоставе рядом появляется толщина льда в сантиметрах; кнопка добавления расположена под полями.
- Толщина льда хранится отдельно от рабочей глубины воды, округляется при вводе до двух десятичных знаков и отображается отдельным графиком.
- Изменение первой или второй глубины на вертикали с введёнными скоростями требует подтверждения. Отказ сохраняет данные; подтверждение очищает скорости только этой вертикали. Время полевых измерений скоростей от этого не меняется.
- При повышении уровня можно выбрать для каждого берега вертикальное продолжение или продолжение крайнего склона. При понижении пересчитывается затопленная часть профиля. Исходные промеры сохраняются, новое положение уровня показано пунктиром.
- Предупреждения о нулевых глубинах, осушении скоростных вертикалей и разделении сечения. Неподдерживаемый расчёт по нескольким водным участкам блокируется.
- Все CSV используют одну схему из 88 столбцов, включая старые измерения. Полные настройки, исходные значения, даты, комментарии и метаданные фотографий содержатся в дополнительных JSON-столбцах. Спецификация: docs/CSV_FORMAT.md.
- Уточнены оформление фотографий, справки, порядок отрисовки профиля. Отправка Android-файлов открывает внешний обработчик отдельной задачей.

## Совместимость

Сохранённые измерения и архивы прежних версий поддерживаются. Просмотр старой записи сохраняет прежний алгоритм геометрии; переход к редактированию промеров включает правила 4.4. Формулы осреднения скоростей и их индивидуальные настройки сохранены. В CSV алгоритм геометрии указан явно.

Для переноса полных измерений с фотографиями используйте .krv. CSV содержит сведения о фотографиях, но не сами изображения. Перед обновлением рекомендуется сохранить важные измерения в .krv.

## Quick start (English)

An offline field application for recording hydrometric measurements and calculating
water discharge and cross-section geometry. Russian and English interfaces; PDF/CSV
reports and .krv archives with photographs. Author: Oleg Loshkov. Apache-2.0.

Use Flutter **3.41.6** (Dart **3.11.4**) and run:

```sh
flutter pub get --enforce-lockfile
flutter analyze --no-pub
flutter test --no-pub --concurrency=1
flutter run
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for development and numerical validation,
[CHANGELOG.md](CHANGELOG.md) for changes, [SECURITY.md](SECURITY.md) for private security reports,
and [CITATION.cff](CITATION.cff) for version-specific scientific citation.

### Scientific limitations / Ограничения

Results require checking against the chosen measurement method and field conditions.
For disconnected wetted sections, version 4.5 warns but uses the existing combined
algorithm; individual channels and their bank coefficients are not modelled.
Automated tests do not certify suitability for a particular engineering decision.
Android device installation and production signing are not verified by the source release.

Версия 4.5 не моделирует отдельные рукава разделённого сечения и их береговые коэффициенты.
Предупреждение об этом не заменяет методическую проверку результата.
