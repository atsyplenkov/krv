# Калькулятор расходов воды 4.3

Версия 4.3.0+10. Android applicationId: krv.app.

## Изменения

- После успешного добавления промерной вертикали фокус возвращается в поле расстояния и открывается клавиатура.
- Второй берег вводится отдельными полями. Можно продолжать обычные промеры, не теряя черновик второго берега. Переключение метров и сантиметров переводит оба набора полей.
- Фото находятся сразу после комментария на экранах промеров, скоростей и результата. Добавление, подписи и удаление доступны также после окончательного сохранения.
- Полностью пустые столбцы скрываются в обеих таблицах результата. Нули остаются данными. Формат CSV не сокращается; прежние записи сохраняют свой совместимый формат.
- В обычных условиях подсказка 0.6h доступна от h ≥ 1.2D.
- В особых условиях (общий ледостав или местные ледовые явления/растительность): при h < 1.2D подсказок нет; от 1.2D до 5D — только 0.5h; от 5D до 10D — 0.15h, 0.2h, 0.5h, 0.8h, 0.85h; от 10D — все горизонты. Подсказки в сантиметрах с одним знаком после запятой. Изменение подсказок не меняет формулы осреднения.
- Сохранение языка обновляет уже открытые экраны, сохраняя их состояние и введённый текст.
- Содержимое окна получения координат выровнено по центру.
- В карточках главного экрана PDF расположен над CSV.
- В английских обозначениях поверхности используется Usur, включая нижний индекс в формулах и отчётах.
- Импорт и экспорт .krv, фотографии, прежние расчётные методы и сохранённые записи остаются совместимыми.

## Сборка

Запустить build_release_wdc.bat из этой папки. Результат: wdc_v4_3.apk, основной идентификатор krv.app. APK версии 4.3 при подготовке исходников не собирался по просьбе пользователя.

Сценарий больше не выбирает старый идентификатор. Старые APK 4.2 и прежний сценарий legacy перенесены в validation/previous-4.2, чтобы не путать их с новым выпуском. Их не следует считать APK 4.3.

Для автоматического запуска без ожидания клавиши: WDC_NONINTERACTIVE=1.
